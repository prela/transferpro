# Dispatcher day prototype

This branch is `chore/206-prototype`. It is not merged, and it does not open a pull request.

Start it with:

```bash
pnpm prototype
```

Then open [http://localhost:3000/prototype?variant=adr-36](http://localhost:3000/prototype?variant=adr-36).

| Path | Screen |
| --- | --- |
| `/prototype` | Home |
| `/prototype/transfers?ride=r05` | Transfers with the ride detail |
| `/prototype/driver` | Driver, Sljedeća vožnja |
| `/prototype/driver?tabla=1` | Prikaži tablu |

`?variant=` is one of `adr-36`, `adr-40`, `lift-36`, `lift-40`. The bar on the page shows the variant and the token values. Theme and language sit on that bar and in the profile menu.
